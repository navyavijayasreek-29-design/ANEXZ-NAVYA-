# SecureCorp Security Assessment

## Project Overview
This project focuses on assessing the security of a sample web application in a controlled lab environment.

## Tools Used
- Kali Linux / Linux
- Metasploitable 2
- DVWA
- Nmap
- Wazuh
- VirtualBox

## Project Objectives
- Identify open ports and running services.
- Test common web application vulnerabilities in DVWA.
- Monitor security events using Wazuh.
- Document findings and recommend security improvements.

## Methodology
1. Set up the virtual lab.
2. Scan the target using Nmap.
3. Perform authorized DVWA security tests.
4. Review logs and alerts in Wazuh.
5. Prepare a security assessment report.

## Disclaimer
All security testing is performed only in an authorized lab environment.
